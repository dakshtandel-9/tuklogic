# Progress updates (every chat, every task)

1. **Before starting**, post one line with an estimate:
   `Plan: ~N Claude tokens needed · ~M min`
2. **About every 2 minutes while working**, post one short line, and keep working (don't pause or wait for a reply):
   `~X% done · ~Y min left · ~A tokens used / ~B tokens still needed`
3. Nothing else in these updates: no extra explanation.
4. Token and time figures are estimates. Label them with `~`.

# Use few Claude tokens

- Read only the files or line ranges you need. Don't re-read files you already have.
- Keep replies short. No long summaries or recaps.
- Don't start subagents unless asked.
